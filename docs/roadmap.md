# Роадмап

- Статус: **принято** (2026-10-03)

Задача: урезать MVP до того, что реально нужно двоим пользователям каждый день, а остальное разложить по релизам. Архитектурные заделы (ADR-0003, учёт в ADR-0004) делаются сразу — они дешёвые сейчас и дорогие потом.

## R0 — «Для нас двоих» (MVP)

| Область | Входит | Урезано до R1 |
|---|---|---|

## R1 — «Семейный диспетчер» (ядро продукта)

- **Уведомления об изменениях (US-72)** — ✅ *R0-часть, 2026-10-06*: синхронизация Google (push `events.watch` за флагом `GOOGLE_PUSH_ENABLED` / опрос раз в 5–15 мин, `syncToken`, 410, продление каналов, суточная сверка), изменения через бота — в другие чаты с автором, внешние — во все, эхо по etag, сводка пачки, тихие часы, вкл/выкл в `/settings`. Групповой чат дома и участники без Google — ✅ по ревью R1. Осталось: выбор календарей, живая проверка push на workers.dev ([research/google-push.md](research/google-push.md)).
- **Напоминания в Telegram (US-71)** — ✅ *2026-10-06*: «за N минут» в `/settings`, по снимкам синхронизации — переносятся и снимаются вместе с событием. Механизм задач — общий с поручениями (US-91).

Позиционирование и обоснование — [research/pivot-options.md](research/pivot-options.md).
- Участники без Google, приглашение в дом (US-90).
- Поручения и напоминания другому участнику с «Беру / Не могу» и эскалацией (US-91); ответственный и «для кого» у события (US-92).
- Напоминания в Telegram (US-71) — общий механизм с поручениями — ✅ 2026-10-06: «за N минут» в `/settings` → «📣 Уведомления», пересчёт при изменениях; уведомления об изменениях (US-72) — ✅ 2026-10-06 (личные чаты; синк Google: опрос, push за флагом `GOOGLE_PUSH_ENABLED`).
- Семейный вечерний брифинг «Завтра» с блоками «кто отводит / что подготовить» (US-93); дайджесты «Завтра» и «Неделя» (US-70) — ✅ 2026-10-06: обе в `/settings` → «☀️ Сводка», по умолчанию выключены.
- Событие из чужого контента: пересланные сообщения (US-65), скриншоты и фото (US-66), `.ics` (US-67) — ✅ 2026-10-06, база: кнопка «📅 Создать событие из этого» на пересланном, фото → Gemini → карточка, `.ics` → карточка «Добавить в календарь?». Пробелы (несколько событий, склейка пачки пересланных, дубликаты, `UID`) — в user-stories.
- Бот в семейном групповом чате (US-94), inline-карточка «📅 Добавить себе» (US-95).

## R2 — «Удобство»

- ~~Доверительный режим (US-05)~~ — снят с роадмапа (решение владельца 2026-10-09): подтвердить кнопкой несложно, смысла нет.

Пояс календаря отличается от текущего (поездка) — в карточках создания и переноса и его время: «🗓 В поясе календаря (Europe/Moscow): 11:00».

- Настройки голосом (из аудита R0, п. 7): длительность по умолчанию, другое имя календаря, «я переехал в …» — смена домашнего пояса; настройка уведомлений голосом, подсказки о функциях (US-64).
