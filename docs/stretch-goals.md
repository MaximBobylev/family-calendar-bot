# Stretch goals

Возможные будущие фичи и их влияние на архитектуру. Что из этого закладывается в MVP — в [ADR-0003](adr/0003-domain-model-and-boundaries.md) и [ADR-0004](adr/0004-monetization.md).

Ценность / влияние на архитектуру (если не заложить заранее): Н / С / В.

| Идея | Ценность | Влияние | Задел в MVP |
|---|---|---|---|
| Несколько Google-аккаунтов (личный + рабочий) | В | **В** | `User 1—N ProviderAccount`, ссылки на события с `accountId` |
| Outlook / Microsoft 365 | В (для продаж) | **В** | `CalendarProvider`, нейтральная модель `Event` и `Recurrence` |
| iCloud (CalDAV), Яндекс.Календарь | С | **В** | то же + тип учётных данных у аккаунта, `capabilities` провайдера |
| ~~Бот в семейном групповом чате~~ | — | — | **перенесено в R1** (US-94) |
| Платные тарифы, семейный тариф | В | **В** | `Entitlement` + `authorize()`, учёт расходов |
| Другие каналы (веб, WhatsApp, Siri Shortcuts / HTTP API) | С | **В** | `ChannelAdapter`, `InboundMessage` / `Reply`, внутренний `user_id` |
| ~~Фото / скриншот приглашения → событие~~ | — | — | **перенесено в R1** (US-66) |
| ~~Пересланные сообщения, `.ics` → событие~~ | — | — | **перенесено в R1** (US-65, US-67) |
| Google Tasks / to-do | В | С | хранение `granted_scopes`, инкрементальная авторизация |
| Приглашения и контакты (US-80) | С | С | `attendees[]` в модели `Event` |
| Общее свободное время нескольких людей | В (семья) | С | `freeBusy` в `CalendarProvider` |
| ~~«От имени» другого / поручения~~ | — | — | **ядро продукта, R1** (US-91) |
| Telegram Mini App (визуальный календарь, настройки) | С | С | ядро отделено от Telegram |
| Умные напоминания (подготовка, «завтра рано») | С | С | единый планировщик `ScheduledJob` |
| Локализация на другие языки | С | С | i18n-каталог с первого дня, `Intl` для дат |
| MCP-сервер / API для других ассистентов | Н–С | С | единый реестр интентов со схемами |
| Пакетные операции, «освободи пятницу» | С | Н | undo-журнал как список операций |
| Геолокация и время в пути | С | Н–С | `location {text, lat?, lon?}` |
| Шаблоны встреч («поставь стендап») | С | Н | настройки как версионируемый JSON |
| Zoom / Meet ссылки | С | Н | поле `conference?` в `Event` |
| BYO API key, локальные модели | Н–С | Н | выбор провайдера от `(user, config)` |
| Аналитика времени, семантический поиск | Н | Н | ничего |
| Импорт расписаний, вебхуки наружу | Н | Н | ничего |

Реализации других провайдеров и каналов, household / роли, локальная копия календаря, записная книжка, event-bus, аналитика.
