# Экономика хостинга: Cloudflare Workers vs VPS + Go (2026-10-03)

Расчёт агента по официальной документации (лимиты и цены на 03.10.2026). `[?]` — не подтверждено официальным источником.

## Модель нагрузки (на активного пользователя в день)

11 команд (8 голосовых по ~7 с), ~16.5 вызовов LLM (~37k входных, ~3.3k выходных токенов), ~45 вызовов Workers, ~85 вызовов Google Calendar API, ~200–400 записей строк в БД.

- **11 команд/день — потолок активного, а не среднее.** Реалистичное среднее 3–6 → AI-расходы ×0.3–0.5.
- **Эхо push-уведомлений:** изменения самого бота тоже приходят push'ем; общий календарь, на который подписан каждый член семьи, даёт дубли → **одна подписка на календарь**, а не на пользователя, и отбрасывание своих изменений.
- gpt-oss — reasoning-модели: токены рассуждений оплачиваются как выходные, реальный выход может быть 500–1000 токенов `[?]` — замерить в бенчмарке.

## Cloudflare Workers Free

| Лимит | Хватает на пользователей |
|---|---|
| **Workers AI: 10 000 neurons/день** (на Free докупить нельзя) | **5** (Llama 3.3 70B) · **12** (gpt-oss-20b) · **~30** (Qwen3-30B-A3B) |
| KV: 1 000 записей/день | ~28 — **KV только для кеша**, состояние в D1/DO |
| Queues: 10 000 операций/день | ~120 (каждый апдейт в очередь) · ~300 (только тяжёлые команды) |
| D1: 100k записей строк/день, 5M чтений, 500 МБ на БД | ~250–500 по записи |
| Durable Objects (SQLite): 100k запросов, 13 000 ГБ·с/день | ~650 (если ждать AI внутри DO) · ~2 800 по запросам |
| Workers: 100 000 запросов/день | ~2 200 |
| CPU 10 мс на вызов | хватает для типичного обработчика; риск — большие синхронизации и пакетная обработка в одном вызове |
| 50 subrequests на вызов | дайджесты раздавать по отдельным вызовам |

**Узкое место — Workers AI (5–30 пользователей).** Без AI платформа на Free держит **~100–300** при аккуратном дизайне.

## Cloudflare Workers Paid ($5/мес)

Включённых объёмов хватает **примерно на 400–1 000 пользователей** без AI; при 1 000 — ~$8–9/мес. Лимиты на вызов: CPU до 5 мин, 10 000 subrequests. Workers AI сверх 10k neurons/день — $0.011 за 1 000 neurons.

## AI — отдельно от хостинга

Workers AI доступен по REST с любого сервера (та же дневная квота `[?]`).

| Провайдер / модель | $/польз./мес (полная модель нагрузки) | Free-квота |
|---|---|---|
| Workers AI: Whisper turbo + Llama 3.3 70B | $0.56 | → 5 польз. |
| Workers AI + gpt-oss-20b | $0.27 | → 12 |
| Workers AI + Qwen3-30B-A3B | **$0.10** | → ~30 |
| Groq: whisper turbo + gpt-oss-20b | ~$0.14 | 200k токенов/день на модель → ~5; лимит 8k токенов/мин → 429 при одновременных командах |
| DeepInfra: whisper turbo + gpt-oss-20b | **~$0.05** | нет free, нужна карта |
| OpenRouter `:free` | $0 | 1 000 запросов/день при ≥ $10 кредитов → ~60; риски приватности/стабильности |

**При 1 000 пользователей AI — $50–560/мес, на 1–2 порядка дороже хостинга.** Выбор модели по бенчмарку влияет на бюджет в 5–10 раз сильнее, чем выбор хостинга. Экономия: кеш статической части промпта (~1 500 из ~2 250 входных токенов), один вызов LLM на команду вместо 1.5.

## VPS + Go + SQLite + Caddy

- Hetzner CX23 (2 vCPU, 4 ГБ) €5.49 + IPv4 + бэкапы 20% ≈ **€7.1 (~$8.3)/мес**. Дешевле `[?]`: netcup ~€4, OVH от €3.5, Contabo от €4.5.
- Тянет **10 000+** пользователей (I/O-bound); упираться будут Telegram (30 сообщений/с) и Google (10 000 запросов/мин на проект).
- Сверху: домен ~$10–12/год (нужен в любом варианте — верификация Google), Caddy + Let's Encrypt, бэкапы (Hetzner / Litestream в S3/R2), мониторинг (Healthchecks/UptimeRobot), unattended-upgrades.
- **Эксплуатация:** первичная настройка 6–12 ч, дальше **1–3 ч/мес** + инциденты (CF — ~0.5 ч/мес, но больше усилий на проектирование под лимиты).

## Оплата (риски)

- Hetzner не обслуживает клиентов с российским адресом → нужен грузинский адрес ИП и карта; возможна KYC по паспорту, исход с паспортом РФ не гарантирован `[?]`.
- Cloudflare не принимает карты подсанкционных банков; грузинская Visa/Mastercard по опыту сообщества обычно проходит `[?]`. Тот же риск для Groq, DeepInfra.

## Технические особенности Workers

- STT+LLM 3–8 с — это wall time, не CPU. `ctx.waitUntil` продлевает работу до 30 с после ответа, но может оборваться при деплое → inbox в D1 + cron-подметальщик повторов (Queues надёжнее, но 10k операций/день на Free).
- Push Google: HTTPS с валидным сертификатом (workers.dev или свой домен — ок), тела нет → `events.list` по `syncToken`, продление каналов кроном.
- Напоминания: cron раз в минуту (задержка до ~60 с, индекс по `due_at`) или DO alarms (точнее, at-least-once, ~7 запросов DO на пользователя в день).
- Google Calendar API пока бесплатен; объявлена тарификация сверх квоты «later in 2026» (порог ~1M запросов/день на проект `[?]`) — для беты неактуально.

## Вывод

1. CF Free заканчивается на **5–30 пользователях из-за Workers AI**, а не из-за хостинга; сама платформа держит ~100–300.
2. На горизонте беты (≤100) CF Paid ($5) и VPS (~$9) почти равны по деньгам; разница — в эксплуатации (CF ~0) против свободы модели исполнения (VPS: нет лимитов на вызов, простой планировщик и inbox).
3. Доминирует AI: модель по бенчмарку решает бюджет сильнее, чем хостинг.
4. Непроверенное: приём грузинской карты CF/Hetzner/Groq/DeepInfra, токены рассуждений gpt-oss, будущая тарификация Google Calendar API.
