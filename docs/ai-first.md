# Готовность к разработке AI-агентами (аудит 2026-10-05)

Почти весь код написан агентами, часто несколькими параллельно в одной рабочей копии. Вопрос аудита: насколько быстро и безопасно агент (Claude Code и подобные) находит нужное, проверяет себя и не ломает прод/чужую работу.

**Итог.** База была сильной: спецификация первична, переносимые тесты-данные, фейки и внедряемые часы дают детерминированную проверку за ~30 с, весь тулчейн в Docker, `.env` замаскирован в контейнерах. Не хватало «входной двери» для агента (инструкций, карты кода), выборочного прогона сценариев с внятной ошибкой фильтра, предохранителя от расхода квот на живых замерах и конфигурации прав Claude Code. Это добавлено; крупные структурные улучшения — в рекомендациях.
