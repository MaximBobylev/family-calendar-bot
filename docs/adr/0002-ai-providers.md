# ADR-0002. Провайдеры STT и LLM

- Статус: **принято** (2026-10-04): на старте — самые дешёвые модели (Whisper large-v3-turbo + Qwen3-30B-A3B на Workers AI, ADR-0005 п.7); бенчмарк ниже — только при проблемах с качеством

## Контекст

Нужны два шага: распознавание речи (STT) и разбор интента (LLM с tool calling) на русском, английском и смешанной речи.
Хочется держать всё в инфраструктуре Cloudflare, но внешние провайдеры допустимы.

Кандидаты:

| Шаг | Основной | Альтернатива |
|---|---|---|
| STT | Workers AI: `@cf/openai/whisper-large-v3-turbo` | Groq: `whisper-large-v3` / `whisper-large-v3-turbo` (бесплатный тариф с дневным лимитом аудио) |
| LLM | Workers AI: модель с function calling (Llama 3.3 70B, Qwen и др.) | OpenRouter: отдельный аккаунт, $10 на балансе, бесплатные модели |

## Решение

1. **Слой абстракции провайдеров:** `SpeechToText` и `IntentParser` — интерфейсы. Реализации: Workers AI, Groq, OpenRouter. Выбор через конфиг, без изменения кода.
2. **Цепочка fallback:** основной провайдер → при ошибке, таймауте или исчерпании лимита → альтернативный. Факт переключения логируется.
3. **По умолчанию — Workers AI** для обоих шагов (одна инфраструктура, один биллинг, binding без ключей). Основной провайдер меняем, только если бенчмарк покажет заметно лучшее качество у альтернативы.
4. Можно рассмотреть [Cloudflare AI Gateway](https://developers.cloudflare.com/ai-gateway/) перед внешними провайдерами: единые логи, кеш, ретраи, rate limiting.

## Протокол (решено 2026-10-04)

LLM вызывается по **OpenAI-совместимому HTTP API** (`/chat/completions` + `tools`), а не через биндинг Workers AI:
- один протокол у Workers AI (`https://api.cloudflare.com/client/v4/accounts/<id>/ai/v1`), Groq, OpenRouter, DeepInfra — fallback-провайдер = другой `LLM_BASE` + ключ;
- в тестах `LLM_BASE` указывает на фейк (ADR-0006), биндинг AI в `wrangler dev` работает только удалённо;
- переносимо на Go без изменений.

Цена: для прода нужны account id Cloudflare (в `LLM_BASE`) и API-токен с правом Workers AI (секрет `LLM_API_KEY`).
STT — REST Workers AI `/ai/run/@cf/openai/whisper-large-v3-turbo` (OpenAI-совместимого `/audio/transcriptions` у Workers AI нет — проверено). Замер 2026-10-04 на синтетическом голосе: OGG/Opus из Telegram принимается как есть, 1–4.5 с; числа и даты распознаются хорошо («в 15.30», «с 10 по 20 ноября»), имена искажаются («Созвон с Петей» → «Созван спеть и») — поэтому карточка перед созданием; на тишине без `vad_filter` — «Thank you.», с `vad_filter` — пусто; жёсткий `language` ломает английский, `initial_prompt` не помогает.

## Замер на Workers AI (2026-10-04)

Мини-бенчмарк 18 фраз (RU/EN), промпт с примерами, tool calling через OpenAI-совместимый API:

| Модель | Результат | Время | Проблемы |
|---|---|---|---|
| Qwen3-30B-A3B, `/no_think` | 12/18 | ~0.5 с | возвращает только `start` и `title`; теряет части дат («с часу до двух» без «в пятницу»); ломает JSON на полях после `title`; без `/no_think` — 5–7 с и битый JSON |
| gpt-oss-20b | 0/18 | — | не отдаёт tool calls через этот API |
| Llama 3.3 70B | 13/18 | ~3.5 с | уходит в повторы до лимита длины |

**Изменение событий (замер того же дня):** Qwen3 верно выбирает `modify_event`, но не заполняет «какое событие» и выдумывает `reference`/`scope` (например, `last` для «сдвинь планёрку») — эти поля берутся из текста детерминированно (`src/nlu/modify-hints.ts`), от LLM — только интент; сильные глаголы («перенеси», «сдвинь», «переименуй») переопределяют интент.

**Вывод:** даты нельзя доверять LLM даже как фрагменты. Даты и длительность извлекаются из текста детерминированно (ADR-0005 п.3, `src/dates/extract.ts`); LLM отвечает за интент, название и календарь. Остаёмся на Qwen3-30B (`/no_think`, `title` последним в схеме, нестрогий разбор битого JSON).

## Цепочки провайдеров (реализовано 2026-10-05)

- Причина: бесплатный план Workers AI — 10 000 neurons/сутки на аккаунт; замеры промпта (≈3,8 тыс. вызовов) исчерпали их, и бот до сброса не разбирал команды. Для разработки — бесплатные внешние модели, Workers AI — запасной.
- **LLM:** OpenRouter, несколько моделей по очереди (`OPENROUTER_MODEL`; по умолчанию с 2026-10-05 — `nvidia/nemotron-3-super-120b-a12b:free` → `google/gemma-4-26b-a4b-it:free`, у Gemma `reasoning.enabled=false`; замеры — docs/research/llm-intents-eval.md) → Workers AI (Qwen3-30B). Актуальный порядок — `OPENROUTER_DEFAULT` в `scripts/deploy.ts`.
- **STT:** Groq (`whisper-large-v3-turbo`, OpenAI-совместимый `/audio/transcriptions`, multipart) → Workers AI (Whisper, REST `/ai/run`). У Groq нет `vad_filter` — тишину ловит стоп-лист галлюцинаций.
- Переключение — на любую ошибку провайдера (429, 5xx, таймаут, сеть); пустой ответ без tools — не ошибка. В журнале (`usage_events.provider`) — тот, кто ответил; упавшие до него — в `result_json.fallbackFrom`.
- Конфиг: секреты `LLM_CHAIN` / `STT_CHAIN` (JSON), собирает `scripts/deploy.ts` из `OPENROUTER_API_KEY`, `GROQ_API_KEY` (+ необязательные `OPENROUTER_MODEL`, `GROQ_STT_MODEL`); без ключей — один Workers AI, как раньше.
- **Приватность:** бесплатные модели OpenRouter могут логировать запросы и использовать их для обучения; Groq хранит данные по своей политике. Для нас двоих — приемлемо; **до публичной беты** — платные эндпоинты без логирования (или Workers Paid) и перечислить провайдеров в privacy policy.
- Лимиты бесплатного OpenRouter: ~20 запросов/мин; 50/сутки без покупки кредитов, 1000/сутки при балансе ≥ $10 — дальше срабатывает запасной Workers AI.
- Тесты: в dev обе цепочки — фейки (`/llm`, `/llm-backup`, `/stt-openai`, `/stt`), отказ включается шагом `provider_outage` (acceptance/scenarios/19-providers.yaml).

## Как выбираем

Перед реализацией собираем **тестовый набор**: 50–100 фраз (RU / EN / смешанные) с ожидаемым интентом и слотами, плюс 15–20 записанных голосовых. Прогоняем всех кандидатов и сравниваем:
- STT: точность (особенно числа, время, имена, англицизмы) и задержку;
- LLM: точность интента, точность слотов (даты!), валидность JSON/tool calls, задержку.

Этот же набор потом становится регрессионными тестами.

## Риски и последствия

- **Бесплатные модели OpenRouter:** жёсткие лимиты запросов в сутки и в минуту (зависят от баланса аккаунта). Часть бесплатных провайдеров может логировать промпты или учиться на них, а в промпте будут названия встреч и имена. Нужно проверить настройки приватности аккаунта и выбирать модели без логирования.
- **Groq free tier:** лимиты по аудио в час и в сутки — на двоих хватает с запасом, для платной версии нет.
- Разные провайдеры по-разному поддерживают tool calling → контракт `IntentParser` должен опираться на JSON-схему и валидацию, а не на особенности одного API.
