# ADR-0004. Монетизация и платный доступ

- Статус: **черновик / один из вариантов** (2026-10-03). **Решено для беты:** 30 дней полного доступа → пропуск на 30 / 365 дней без автопродления, без постоянного free до верификации Google (см. monetization-evaluation.md). Модель монетизации обсуждается в [monetization-brainstorm.md](../monetization-brainstorm.md); раздел «Себестоимость» и архитектурный задел (entitlements, учёт) остаются актуальны при любом варианте.
- Факты о ценах и правилах — по состоянию на октябрь 2026, перед запуском перепроверить.

## Контекст

Сейчас бот для двоих (ADR-0001). Если понравится — дешёвая подписка или lifetime. Обязателен триал с полным функционалом; бесплатный уровень — под вопросом.

## Себестоимость

Сценарий: 10 голосовых в день (~300/мес), ~7 сек каждое, ~1.5 вызова LLM на команду, ~2 500 токенов на вход.

| Статья | $/мес на пользователя |
|---|---|
| STT (Workers AI Whisper turbo, ~$0.0005/мин) | ~0.02 |
| LLM (Llama 3.3 70B на Workers AI) | ~0.5 |
| LLM (gpt-oss-120b / Llama 4 Scout) | ~0.4 |
| Workers, D1, DO, Google API | ~0 (в рамках $5/мес за аккаунт Workers Paid) |
| **Итого** | **~$0.4–0.6**, тяжёлый пользователь ~$2 |

Выводы: ~95% затрат — LLM, а не распознавание. «Только текст» стоит почти столько же, сколько голос. Главный рычаг экономии — размер промпта (схемы интентов, контекст). Для двоих пользователей хватает бесплатных 10k нейронов в сутки.

## Предлагаемая модель

**Триал 14 дней (всё включено) → подписка в Telegram Stars**, после триала — **бесплатный уровень** с функциями без AI и жёстким лимитом изменений.

| Тариф | Цена | Что входит |
|---|---|---|
| Триал | 0, 14 дней | Всё. Предохранитель — 200 AI-запросов |
| Бесплатный (после триала) | 0 | Дайджесты, напоминания, кнопки без AI + лимит успешных изменений (см. «Бесплатный уровень») |
| Personal | ~200 ⭐/мес | Всё; fair-use 600 AI-запросов/мес |
| Family (2 места) | ~300 ⭐/мес | Как Personal на 2 Telegram-аккаунта, у каждого свой Google |
| Год | ~1 900 ⭐ разово | 12 месяцев Personal, без автопродления |
| Founder lifetime (ограниченная серия 50–100) | ~4 000 ⭐ | Personal навсегда, fair-use 300 голосовых/мес, сверх — только текст или свой API-ключ |

Нетто автору ~$0.013 за звезду (вывод через Fragment в TON) → Personal даёт ~$2.6/мес при себестоимости ~$0.5.

### Почему так

- **Lifetime без ограничений** опасен: AI-расходы переменные и бессрочные. Только ограниченная серия с fair-use.
- Любые бесплатные пользователи занимают слоты в лимите 100 OAuth-пользователей → бесплатный уровень открываем публично только после верификации Google.

### Бесплатный уровень (решено: нужен; параметры — считаем)

Автор: бесплатное должно быть обязательно. Кандидаты — отключить голосовой ввод или жёсткий лимит в 2–3 успешных создания/изменения в день или неделю.

Важно для экономики: **голос почти ничего не стоит** (~$0.0001 за голосовое), ~95% затрат — LLM, которая нужна и для текста. Поэтому:
- «без голоса, текст без лимита» — это **не** экономия, а только продуктовый рычаг (удобство как платная ценность). Расходы на активного бесплатного пользователя ≈ как на платного (~$0.4–0.5/мес);
- реально ограничивают затраты только **лимиты на вызовы LLM**.

Рабочий вариант для обсуждения:

| В бесплатном | Стоимость |
|---|---|
| Дайджесты, напоминания в Telegram, кнопки «Сегодня / Завтра / Неделя» (без LLM) | ~0 |
| N успешных изменений календаря (create / modify / delete) в неделю — голосом или текстом | ~$0.0017 × N |
| Скрытый потолок на все вызовы LLM (чтение, уточнения, неудачные попытки) — защита от абьюза | ограничивает худший случай |
| Платное: без лимитов (fair-use), доверительный режим, дайджест недели и т.п. — состав уточнить | — |

Пример: 3 изменения в день + потолок 150 LLM-вызовов в месяц → худший случай ~$0.25/мес на бесплатного пользователя. Пользователю показываем понятную метрику («осталось 2 изменения на сегодня»), а не «LLM-вызовы».

Что ещё посчитать: долю платящих при разных лимитах, точную стоимость промпта после оптимизации, где проходит граница бесплатных Workers AI нейронов.

### Триал

- Отсчёт — с момента успешной привязки Google, а не `/start`.
- Напоминания за 3 дня и за 1 день до конца.
- После окончания: включается бесплатный уровень; сверх лимита команды → «лимит на сегодня исчерпан» + кнопка оплаты; аудио сверх лимита не обрабатывается; настройки и токен сохраняются.
- Защита от повторного триала — по хешу Google-аккаунта, а не только Telegram.

### Семейный тариф

Владелец покупает Family → получает одноразовую deep-link `t.me/<bot>?start=fam_<code>` → второй участник вступает, его entitlement следует за подпиской владельца. Квоты — у каждого свои.

### Оплата

- **Внутри бота — только Telegram Stars**: правила Telegram требуют Stars для цифровых товаров, иначе бот рискует пропасть из мобильных клиентов. Подписка — `createInvoiceLink` с `subscription_period` 30 дней; годовой — разовый платёж. Обязательны `/terms`, `/support`, `/paysupport`, возвраты через `refundStarPayment`.
- **Проблема RU-аудитории:** российской картой Stars напрямую обычно не купить.
- **Внешние платёжки** (ЮKassa для самозанятых, Paddle / Lemon Squeezy как MoR — последние не работают с РФ) — только на сайте с кодом активации `/redeem`; серая зона по правилам Telegram.
- **Юрисдикция автора:** самозанятый в РФ + ИП в Грузии. Для международных продаж логичнее грузинское ИП (выплаты из Stars через Fragment/TON, внешние MoR-платёжки — проверить, какие работают с продавцами из Грузии), для RU-покупателей — самозанятость + ЮKassa через сайт с кодами активации. Детали учёта выплат в TON — к бухгалтеру/юристу.

## Что заложить в MVP

- Сущность `Entitlement` (`plan`, `source` ∈ {`comp`, `trial`, `stars`, `redeem`, `family`}, `starts_at`, `expires_at`, `limits`). Автор и супруга — `comp` без срока. Allowlist остаётся только ограничителем регистрации до верификации Google.
- Одна функция `authorize(user, feature)` — вызывается **до** скачивания аудио и STT; `feature` ∈ {`ai_voice`, `ai_text`, `notifications`, `read_buttons`}. Матрица план × функция — в коде, без `if`-ов по обработчикам.
- `UsageEvent` (совмещён с журналом US-13) + месячные счётчики для квот; стоимость считается в момент вызова.
- Хеш Google-аккаунта при привязке.
- Учёт использованных функций по пользователю (US-64) — нужен и для подсказок, и для лимитов бесплатного уровня («успешные изменения»).
- Выбор провайдера на уровне пользователя (задел под BYO key).
