# Правила разбора дат и времени

Детерминированные правила, по которым код проверяет и разрешает то, что вернула LLM. Если правило даёт больше одного варианта — слот помечается `ambiguous`, и бот показывает варианты кнопками (US-05).
Все примеры — «сейчас» = среда, 7 октября 2026, 10:00, пояс пользователя.

## Час без уточнения AM/PM

| Сказано | Трактовка |
|---|---|
| «в 1» … «в 6» | 13:00–18:00 |
| «в 7» … «в 11» | 07:00–11:00 |
| «в 12» | 12:00 |
| «в 7 вечера», «в 8 утра», «в 3 ночи», «в 9pm» | как сказано |
| «в 15», «в 21:30» | как сказано |

Карточка всегда показывает время в формате 24 ч.

## День недели

| Сказано | Трактовка |
|---|---|
| «в пятницу» (не сегодня) | ближайшая будущая пятница (9 окт) |
| «в среду» (= сегодня), время ещё не прошло | **ambiguous**: «Сегодня, ср 7 окт» / «Ср 14 окт» |
| «в среду» (= сегодня), время прошло | следующая среда (14 окт) |
| «в эту пятницу» | пятница текущей недели (9 окт) |
| «в следующую пятницу» | **ambiguous**: «Пт 9 окт» / «Пт 16 окт» `[допущение]` — по-русски обе трактовки частые |
| «в пятницу на следующей неделе» | пятница следующей недели пн–вс (16 окт) |

## Время без дня

| Сказано | Трактовка |
|---|---|
| «в 12» (ещё не прошло) | сегодня 12:00 |
| «в 9» (сейчас 10:00) | **ambiguous**: «Сегодня 21:00» / «Завтра 09:00» |

## Периоды суток (для чтения расписания и поиска)

| Сказано | Интервал |
|---|---|
| утро / утром | 06:00–12:00 |
| днём | 12:00–18:00 |
| после обеда | 13:00–18:00 |
| вечер / вечером | 18:00–24:00 |

## Периоды

| Сказано | Интервал |
|---|---|
| «на этой неделе», «покажи неделю» | с сегодня до воскресенья текущей недели |
| «на следующей неделе» | пн–вс следующей недели |
| «предстоящая неделя» (дайджест US-70) | пн–вс следующей недели при отправке в вс; текущей — при отправке в пн |
| «в этом месяце» | с сегодня до конца месяца |

Неделя начинается с понедельника `[допущение]`.

## Длительность

- Не указана → настройка (по умолчанию 1 час).
- «с часу до двух» → явные начало и конец.
- «до полуночи» и переход через полночь допустимы.
