# Правила разбора дат и времени

Детерминированные правила, по которым парсер (`src/dates/`, ADR-0005 п.8) превращает фрагмент, вырезанный LLM, в дату. Если правило даёт больше одного варианта — результат `ambiguous`, бот показывает варианты кнопками (US-05). Если фрагмент содержит незнакомое слово — `unparseable`, бот переспрашивает, а не догадывается.

Исполняемая спецификация — золотой корпус `testdata/dates/` (558 кейсов, `npm test`). Примеры ниже: «сейчас» = среда, 7 октября 2026, 10:00, пояс пользователя.

## Час без уточнения части суток

| Сказано | Трактовка |
|---|---|
| «в 1» … «в 6» | 13:00–18:00 |
| «в 7» … «в 11» | 07:00–11:00 |
| «в 12» | 12:00 |
| «в 15», «в 21:30», «в 0:30» | как сказано |
| «в 7 вечера», «в 4 дня», «в 9pm», «в пятницу вечером в 7» | после полудня |
| «в 8 утра», «в 9am», «в понедельник утром в 9» | до полудня |
| «в 3 ночи», «в 2 ночи» | 03:00, 02:00; «в 11 ночи» — 23:00. С названным днём 1–5 ночи — ночь **после** него: «завтра в 2 ночи» = «завтра ночью в 2» (см. «Периоды для чтения») |
| «в 12 ночи», «в полночь» | 00:00 **следующего** дня |
| «в полдень», «в 12 дня» | 12:00 |
| «в обед» | 13:00 |

Правило применяется к **получившемуся** часу: «без десяти семь» = 6:50 → «6» → 18:50.

Разговорные формы: «полтретьего», «пол-третьего», «в половине третьего» (14:30), «в четверть третьего» (14:15), «без пятнадцати три» (14:45), «без четверти шесть» (17:45), «без двадцати пяти три» (14:35), «в пять минут восьмого» (7:05), «пятнадцать тридцать», «восемнадцать ноль-ноль», «в час дня» (13:00), «half past three», «quarter to 5».

Запись Whisper: «15-30», «15-00», «в 15 30», «15.30», «в 15ч», «9.30pm» — время. «10-12», «завтра 14-16» — интервал «с 10 до 12». «A-15» при A < 15 («в 9-15», «в 11-15») — **варианты:** сначала 9:15, затем интервал 9:00–15:00 (если у 9:15 свои варианты по правилам часа — они идут первыми). Конец не больше начала («в 16-15», «в 20-30») — время 16:15. «в 9-15 вечера» — только 21:15.

Приблизительное время = точное: «часов в 5», «где-то в 3», «около трёх», «примерно в 11».

## Время без дня

| Ситуация | Трактовка | Пример |
|---|---|---|
| Время ещё не прошло | сегодня | «в 12» → сегодня 12:00 |
| Утренний час 7…12 без части суток прошёл, вечерний вариант ещё впереди | **варианты:** сегодня вечером / завтра | «в 9» → «Сегодня 21:00» / «Завтра 09:00» |
| Прошли оба варианта | завтра, без вопроса | «в 9» в 22:00 → завтра 09:00 |
| «в 12» поздно вечером | **варианты:** полночь / завтра полдень | «в 12» в 23:30 → 00:00 / 12:00 |
| Час 1…6 (уже после полудня) прошёл | завтра, тот же час | «в 3» в 16:00 → завтра 15:00 |
| Часть суток указана явно и прошла | ближайшее такое время | «в 8 утра» → завтра 08:00 |
| Время равно «сейчас» | считается прошедшим | «в 10» в 10:00 → 22:00 / завтра 10:00 |

## День назван явно

| Ситуация | Трактовка |
|---|---|
| День в будущем | как сказано, без проверки «прошло ли время»: «завтра в 9» → 09:00 |
| День — сегодня, утренний час 7…12 прошёл, вечер впереди | вечер того же дня без вопроса: «сегодня в 9» → 21:00, «7 октября в 9» → 21:00 |
| День — сегодня, время прошло без вечернего варианта | ошибка `in_past` (переспросить): «сегодня в 8 утра» |
| День в прошлом | `in_past`: «вчера», «вчера в 15» |

## День недели

| Сказано | Трактовка |
|---|---|
| «в пятницу» (не сегодня) | ближайшая будущая пятница |
| «в среду в 12» (= сегодня), время впереди | **варианты:** сегодня / через неделю |
| «в среду в 9» (= сегодня), время прошло | через неделю |
| «в среду» без времени (= сегодня) | **варианты:** сегодня / через неделю |
| «в эту пятницу», «this Friday» | ближайшая пятница; если пятница сегодня — сегодня |
| «в следующую пятницу», «next Friday», «в следующий понедельник» | **всегда варианты:** ближайшая / через неделю после неё |
| «в пятницу на следующей неделе», «next week в среду» | день следующей календарной недели (пн–вс) |
| «в понедельник через неделю» | ближайший понедельник + 7 дней |
| «в среду 14-го» (совпадает) | 14-е |
| «в четверг 14-го» (14-е — среда) | **варианты:** 14-е / четверг той же недели (15-е) |

## Дата без года или месяца

| Сказано | Трактовка |
|---|---|
| «14 октября», «14.10», «14/10», «на 14-е», «23-го», «двадцать третьего» | ближайшая такая дата, сегодня включительно |
| Прошла в этом году: «5 января», «1 октября» | следующий год — **год обязательно показывается в карточке** |
| Число без месяца уже прошло: «третьего» | следующий месяц |
| «29 февраля» в невисокосный год | ближайший високосный |
| «30 февраля», «31 ноября» | `invalid_date` |

## Относительные сроки

| Сказано | Трактовка |
|---|---|
| «через час», «через полтора часа», «in 2 hours», «через 24 часа» | реальное время (с учётом перехода на зимнее время) |
| «через 2 дня», «через неделю», «через день», «через месяц» | календарные дни/месяцы, результат — дата |
| «через сутки», «через двое суток», «через 3 суток» | как «через 24 / 48 / 72 часа» — момент. С названным часом («через сутки в 10») — календарные дни, как «через день в 10». «на сутки позже» = +24 ч, «на сутки» = 24 ч |

## Периоды для чтения

Неделя начинается с понедельника.

| Сказано | Интервал |
|---|---|
| утром / днём / после обеда / вечером / ночью | 06–12 / 12–18 / 13–18 / 18–24 / 00–06 |
| «с утра» | = утром (06–12) |
| «в первой половине дня» / «во второй половине дня» | = утром / днём (06–12 / 12–18) |
| «после полудня», «afternoon» | = после обеда (13–18) |
| «ближе к вечеру», «к вечеру», «под вечер», «late afternoon» | 16–20 (часть суток `late_afternoon`) |
| «<день> ночью», «ночью», «завтрашняя ночь» | ночь **после** названного дня: «завтра ночью» (сейчас среда) = 00–06 пятницы; «ночью», «сегодня ночью» = 00–06 четверга |
| «tomorrow night», «friday night», «at night» | вечер (18–24), как «tonight»; «night» без дня — не дата («Jazz Night», «Movie night» — название, tech-debt #25) |
| «на этой неделе», «на неделе», «покажи неделю», «до конца недели» | с сегодня до воскресенья |
| «на следующей неделе», «next week» | пн–вс следующей недели |
| «в выходные», «на этих выходных» | ближайшие сб–вс |
| «на следующих выходных» | **варианты:** ближайшие / через неделю |
| «в этом месяце», «в октябре» (текущий) | с сегодня до конца месяца |
| «в следующем месяце», «в ноябре» | весь месяц (прошедший месяц — следующего года) |
| «ближайшие 3 дня», «на две недели вперёд» | N дней, включая сегодня |
| «в начале / середине / конце месяца», «в конце ноября», «early next month» | дни 1–10 / 11–20 / 21–последний |
| «в начале / конце недели», «early next week», «late this week» | пн–ср / чт–вс; «в середине недели» — не разбирается |
| «предстоящая неделя» (дайджест US-70) | пн–вс следующей недели при отправке в вс; текущей — при отправке в пн |

Начало / середина / конец: без уточнения — текущий месяц (неделя), с сегодня до конца части; если часть уже прошла — та же часть следующего месяца (недели): «в начале месяца» 25 октября → 1–10 ноября. «этого / этой» — только текущий, прошедшая часть → `in_past`. «следующего / следующей» — целиком. Названный месяц — как «в ноябре» (текущий — с сегодня; прошедший — следующего года).

Ночь после дня — изменение 2026-10-05: раньше «завтра ночью» давало 00–06 завтрашней даты (ночь со среды на четверг). Час из «ночью» после полуночи тоже относится к следующей дате: «завтра ночью в 2» = пятница 02:00. Английское «night» теперь = вечер.

Чужой текст (пересланное, подпись, текст с картинки — US-65/66, `foreignDateSpans`) разбирается по предложениям и строкам, берутся первые два куска с датой (кейсы — `testdata/extract/foreign.yaml`):
- первый — только день, второй — только время: склеиваются («Собрание в пятницу.» + «Начало в 18:30.»; «Saturday, Oct 24» + «Doors 7:30 pm»);
- первый — только день, второй — момент со временем в один из его дней: берётся второй («встретимся на выходных?» + «В субботу в 12:30» = суббота 12:30);
- строка из одного времени («14:02», «9:41 PM ✓✓») — время сообщения на скриншоте чата, не событие: пропускается (цена — афиша, где время стоит отдельной строкой без «начало в», даст дату без времени и бот спросит «во сколько?»).

Час «ночи» с названным днём — тоже ночь после этого дня (решение 2026-10-05, п. 14; раньше «завтра в 2 ночи» = четверг 02:00): «завтра в 2 ночи» = «завтра ночью в 2» = пятница 02:00; «сегодня в 2 ночи» = четверг 02:00; «в пятницу в 3 ночи» = суббота 03:00; «завтра с 1 до 3 ночи» = пятница 01:00–03:00. Касается часов 1–5 ночи («в 11 ночи» = 23:00 названного дня, «в 12 ночи» = полночь в его конце — как раньше) и только русского «ночи» («tomorrow at 2am» = четверг 02:00). Без названного дня — правило часа: «в 2 ночи» = ближайшие 02:00 (в 01:00 — сегодня, в 10:00 — завтра).

## Создание события (kind=point)

- Часть суток без часа («завтра вечером», «ближе к вечеру», «во второй половине дня», «завтра ночью») — значение `{date, part}`; бот спрашивает «Во сколько?».
- «first thing tomorrow», «завтра первым делом», «завтра с утра пораньше» → завтра 09:00 (как «в 9 утра»).
- «на неделе», «на этой неделе», «this week» → один день: середина оставшихся будних дней [завтра … пятница], из двух средних — более ранний (пн → ср, вт → чт, ср → чт, чт → пт); в пт–вс → среда следующей недели. Без часа бот спрашивает «Во сколько?». «на этой неделе в 15» → тот день 15:00.
- «в выходные», «на выходных», «на этих выходных», «this weekend» → **варианты:** суббота, затем воскресенье ближайших выходных (значения `date`, с часом — `datetime`: «в выходные в 12» → сб 12:00 / вс 12:00). В субботу — сегодня / завтра; в воскресенье — только сегодня (как при чтении: оставшиеся дни этих выходных). К каждому дню — обычные правила: «в выходные в 9» в субботу 10:00 → сб 21:00 / вс 09:00. «на следующих выходных» не менялось — два периода-варианта.
- «к пятнице», «к 5 ноября», «by Friday», «by tomorrow», «by Oct 14» (к / by + дата) → эта дата, 09:00 (событие-срок утром; напоминания — отдельная функция). С названным часом — этот час: «к пятнице в 15», «by Friday at 3pm» → 15:00. Сегодняшние 09:00 прошли — правило дня недели: «к среде», «by Wednesday» в среду 10:00 → следующая среда 09:00. Для чтения «к пятнице», «by Friday» = сам день.
- «к 18», «к 18:00», «к шести вечера», «к 6 часам вечера», «к двум», «к часу дня», «by 6pm» → этот час по тем же правилам, что «в 18»: «к шести» → 18:00, «к 9» в 10:00 → варианты 21:00 / завтра 09:00, «завтра к 18» → завтра 18:00.
- «к вечеру» = «ближе к вечеру» (16–20): «завтра к вечеру» → `{date, part: late_afternoon}`, бот спрашивает час.
- «в начале / середине / конце месяца (недели)» — период, а не дата: `unparseable`, бот переспрашивает «Когда?».
- Прочие периоды-даты («с 10 по 20 ноября», «в ноябре», «на следующей неделе», «на следующих выходных») возвращаются как `range` из дат; бот создаёт из них событие на весь день(дни).

### Дата из всей фразы и сверка с LLM (ревью 2026-10-08, `docs/research/date-parser-architecture-review.md`)

Извлечение (`src/dates/extract.ts`) не угадывает дату по куску:
- кусок после «не» / «not» — не дата: «не в пятницу, а в субботу в 12» → суббота 12:00;
- куски момента, которые вместе не разбираются («через две недели … во вторник в 9»), порядковый день недели («в первый понедельник ноября», «last Friday of the month»), сдвиг от события («через неделю после дня рождения») — `unsure`: своего куска нет, дата — из `start` от LLM, а если и он не разбирается — вопрос «Когда?». Раньше брался первый кусок (21 октября без времени, 12 октября).

Сверка (`create-logic.ts` `startCheck`, путь команды и пересланного/фото): наш кусок — основной; `start` от LLM — второе мнение, если каждое его слово есть в тексте (не выдумка) и он не часть нашего куска. Наш кусок даёт только день, а `start` — момент → берём `start`; оба момента и разные → оба вариантами (не больше 4). Лог `{"event":"date_check","agreement":…}`: `agree` | `differ` | `ours_only` | `llm_only` | `llm_invented` | `none` (+ `unsure`) — доля расхождений по проду.

## Интервалы событий

- «с часу до двух» → 13:00–14:00; «в пятницу с 10 до 12» → 10:00–12:00.
- Конец интервала — ближайшее подходящее время после начала: «с 23 до 2» → 23:00–02:00 следующего дня.
- Часть суток у конца переносится на начало: «from 1 to 2pm» → 13:00–14:00.
- «с 10 по 20 ноября» — событие на весь день, диапазон включительно.

## Сдвиги и длительности

- «на час позже» → +1 ч; «на полчаса раньше» → −30 мин; «на неделю вперёд» → +7 дней.
- «перенеси на час» без направления → позже.
- Длительность не указана → настройка (по умолчанию 1 час). «часа на три» → 3 ч, «на весь день» → весь день.

## Повторения

- «каждую вторую среду» → раз в две недели; «каждую вторую среду **месяца**» → вторая среда месяца.
- «31 числа каждого месяца» → с предупреждением, что Google пропустит короткие месяцы (US-32).
- Время в правиле — по тем же правилам часа: «каждый понедельник в 3» → 15:00.

## Часовые пояса

- Все значения — в текущем поясе пользователя (US-07).
- «в 12 по Москве», «по МСК» → пересчёт в пояс пользователя.
- Локальное время, которое при переходе на зимнее время бывает дважды, — первое вхождение.

## Разговорные формы и опечатки

- Синонимы: «после завтра» = послезавтра; «ближайшая пятница» = «эта пятница»; «будущая неделя / пятница», «след. неделя» = «следующая»; «текущая неделя / месяц» = «эта»; «вечерком», «утречком», «поутру» = вечером / утром; «на вечер», «завтрашнее утро», «на субботний вечер» — день + часть суток.
- Уменьшительные единицы — те же единицы: «через недельку», «через часик», «через полчасика», «на денёк позже».
- Месяцы сокращённо: «5 ноя», «5 нояб.», «14 окт»; год со словом: «5 ноября 2026 года»; средний род: «первое ноября», «двадцать пятое октября».
- «каждое утро в 8», «каждый вечер в 9» — ежедневно, часть суток уточняет час; без часа — переспросить.
- Опечатки исправляются только по явной таблице (`TYPOS` в lexicon.ts: «завтро», «пятнцу», «tommorow»…), без нечёткого поиска: настоящие слова («пятно», «завтрак») не превращаются в даты. Латинские буквы-двойники внутри русского слова («cреду») заменяются кириллицей.
- «пара» = 2: «через пару дней», «на пару часов», «a couple of hours». «с утра» = утром: «завтра с утра».

## Не разбираются (переспросить)

Неопределённые выражения: «на днях», «скоро», «когда-нибудь», «в середине недели», «после работы», идиомы («после дождичка в четверг»). Сроки — отдельный вид значения для поручений (R1), сейчас не разбираются: «до пятницы», «к обеду», «к утру», «к концу недели», «к концу дня», «к следующей неделе» (и для чтения), «by end of day», «by the end of the week», «EOD», «end of day». Исключения — «к / by + дата», «к + час» и «к вечеру» (см. «Создание события»).
