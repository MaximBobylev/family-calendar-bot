## Решено 2026-10-05: даты, разговорные формы

Решения автора по 13 предложенным пунктам → date-rules.md, корпус `testdata/dates/15-decided-colloquial.yaml` (id `dNN-…` = номер пункта).

1. **«пара» = 2** — «через пару дней», «на пару часов», «a couple of days»: подтверждено.
2. **«с утра»** = утром (06–12): подтверждено; при создании — как «завтра утром» без часа.
3. **«ближе к вечеру», «под вечер»** — часть суток 16:00–20:00 для чтения; при создании события бот спрашивает час (как «вечером»). «к вечеру» — срок, как «к обеду» (п. 9), не разбирается.
4. **«первая / вторая половина дня»** = 06–12 / 12–18 (= утром / днём).
5. **«после полудня»** = «после обеда» (13–18).
6. **«в начале / середине / конце месяца»** = дни 1–10 / 11–20 / 21–последний; **«в начале / конце недели»** = пн–ср / чт–вс. При создании события — переспросить (период, а не дата). «в середине недели» не решено — не разбирается.
7. **«на неделе»** = «на этой неделе» для чтения. Для события — один день в середине оставшейся части недели: середина [завтра … пятница], из двух — более ранний; в пт–вс — среда следующей недели.
8. **«first thing tomorrow»**, «завтра первым делом», «завтра с утра пораньше» = завтра 09:00.
9. **Сроки** («к обеду», «к концу недели», «by Friday», «EOD», «end of day») — пока не разбираются (R1, отдельный вид значения). Исключение — «к + дата» (п. 13).
10. **«<день> ночью»** = 00–06 даты **после** названного дня («завтра ночью» в среду = 00–06 пятницы); «tomorrow night» = вечер (18–24), как «tonight». Изменение прежнего поведения.
11. **«через сутки»** = через 24 часа (момент), а не «завтра» как дата.
12. **«в 9-15»** — варианты кнопками: сначала 9:15, затем 9:00–15:00.
13. **«к пятнице», «к 5 ноября»** = сама дата, утро: 09:00 (событие + напоминание; напоминания — отдельная функция). «к 18», «до пятницы» — по-прежнему сроки, не разбираются.
