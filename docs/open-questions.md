# Открытые вопросы

Отвеченные вопросы переезжают в ADR или в user stories.

## Решено

- Правила дат (35 предложенных) подтверждены и перенесены в date-rules.md
- Парсер дат: свой, без chrono-node (замер chrono — 40% и уверенно-неверные ответы) → ADR-0005 п.8
- Планировщик: cron раз в минуту + D1 → ADR-0005 п.6

- Хранилище — D1; inbox — Cloudflare Queues; планировщик — cron раз в минуту + D1 (допущение) → ADR-0005
- Модели на старте — самые дешёвые (Whisper turbo + Qwen3-30B-A3B), бенчмарк — при проблемах → ADR-0002, ADR-0005
- Оплата Cloudflare — автор решает сам (грузинская или бразильская карта)

- Хостинг и язык: **Cloudflare Workers + TypeScript** → ADR-0005, research/hosting-economics.md
- Переносимые приёмочные тесты (данные + чёрный ящик), чтобы пережить возможный переезд на Go → ADR-0006

- Участник без Google может создавать события в общих календарях дома (через аккаунт владельца календаря) и назначать на взрослого/ребёнка → US-90
- Тон напоминаний всегда нейтральный → эпик 9
- Отдельного семейного брифинга нет — это обычный дайджест с семейными данными → US-93
- Изменения событий узнаём через push Google (`events.watch` → webhook → инкрементальная синхронизация), не опросом → ADR-0005 (черновик)
- Даты разбирает детерминированный код, не LLM → date-rules.md, ADR-0005 (черновик)
- Входящие апдейты Telegram — через inbox: быстрый ответ 200, обработка асинхронно → ADR-0005 (черновик)

- **Ядро продукта — семейный диспетчер** (передача дел, участники без Google, ответственный). В R0 — только задел в схеме данных; функциональность — R1 → ADR-0003, роадмап, эпик 9
- Календарь Telegram-каналов — отдельный трек, отложен → tracks/channels-calendar.md

- Встречи, где вы не организатор: без переноса и переименования; «удалить» = отклонить приглашение с явной пометкой в карточке → эпик 5, US-50
- Участников уведомляем всегда (`sendUpdates=all`) → эпик 5, принцип продукта
- Название встречи: явная команда «назови её …» работает всегда, голый ответ — только как reply → US-30
- Часовой пояс: домашний + временный пояс поездки, вопрос «вернулись?» → US-07
- Календари только для чтения показываются при чтении и в дайджестах → US-06, US-20
- Учёт использованных функций для подсказок → US-64
- Час без AM/PM и «в следующую пятницу» → date-rules.md
- Разбивка на релизы R0 / R1 / R2 → roadmap.md
- Бесплатный уровень нужен; юрисдикция — самозанятый РФ + ИП Грузия → ADR-0004

- Аудитория и OAuth → [ADR-0001](adr/0001-audience-and-google-oauth.md)
- Подтверждения настраиваются → US-05 (по умолчанию «осторожный» режим; удаление, массовые операции и изменения серий подтверждаются всегда)
- Языки: русский + английский, включая смешанную речь → US-10a
- Повторяющиеся события входят в MVP → US-32, US-43
- Несколько календарей, календарь по умолчанию, алиасы → US-06
- «В среду», а сегодня среда → две кнопки с датами → date-rules.md
- Нет названия → создаём и спрашиваем название, можно проигнорировать → US-30
- Напоминания по умолчанию — настройка бота, не Google → US-04, US-42
- Ответы только текстом; текстовые команды поддерживаются → US-10a, US-11
- Дайджесты и напоминания в Telegram в MVP, настраиваемые → US-70, US-71
- Календари только на чтение не используем для записи → US-06
- Чтение и дайджесты — по всем подключённым календарям → US-20, US-70
- Пустой дайджест присылаем → US-70
- Язык ответов — из настроек → US-10a
- Распознанный текст логируем → US-13
- Провайдеры STT/LLM → [ADR-0002](adr/0002-ai-providers.md)
